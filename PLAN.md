# Thorough Homesteading plan

Name Thorough Homesteading, id `thoroughhomesteading`, package `com.itmecasey.thoroughhomesteading`, repo and wiki slug `thoroughhomesteading`. MIT. Both sides.
One sentence: a skyblock home for villagers: build a bed and a workstation around a lit Hearth, feed it, and a vanilla villager settles in with the profession of the workstation.

The design spec with every answered decision is `C:\Users\casey\Twitch\Minecraft\Instances\Barely a Mod Pack\design\thorough-homesteading-design-spec.md`; the as-built note is [docs/DESIGN.md](docs/DESIGN.md).

## Targets
Forge and NeoForge on Minecraft 26.1.2, 26.2 and 26.3: six modules plus shared `common/`, one jar per loader and Minecraft version. Java 25.
Forge 64.1.6 / 65.1.6 / 66.1.5, NeoForge 26.1.2.125 / 26.2.0.93 / 26.3.0.101 (same pins as Thorough Chests). Version 2026.11.1.

## Layout (same as Thorough Chests)
- `common/` Minecraft-free logic (tiers, settings, the home check rules, script events, ledger, optional-mod bridges), unit tests, shared resources (lang, textures, models, recipes).
- `version-26.2/` master Minecraft code; `version-26.1.2` and `version-26.3` are generated by `scripts/sync_versions.py` (never edit the copies).
- `forge-<mc>/`, `neoforge-<mc>/` thin loader layers: registration, config, the recipe sync (NeoForge), viewer and look-at plugins (the NeoForge-only ones live there). The 26.1.2 layers are the master of the loader code.
- `scripts/` sync, textures (`make_textures.py`), other resources (`make_assets.py`), server check (`server_check.py`).

## Dependencies
None required. Optional (soft, by reflection or plugin annotations): BEI (`bei-api`), JEI, REI, Show Me What This Is, Jade, ModJS, KubeJS, Barely Questing.
EMI has no build for 26.1.2, 26.2 or 26.3, so there is no EMI plugin; JEI, REI and Jade have no Forge build for these versions.

## Art
Vanilla-derived textures only (`scripts/make_textures.py`). Not approved art.

## Ports
8830 NeoForge 26.1.2, 8831 Forge 26.1.2, 8832 NeoForge 26.2, 8833 Forge 26.2, 8834 NeoForge 26.3, 8835 Forge 26.3.

## Not in the first release
The Caravan, settler jobs beyond vanilla behavior, custom settler looks, ownership of single settlers (see the spec).
